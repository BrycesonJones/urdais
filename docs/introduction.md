# Documentation

Urdais is an information platform for the Information Age. These docs explain how its information products are defined, how their methodologies develop, and the technical foundations that will support them.

## Start with methodology

The [methodology framework](/docs/methodology) establishes a shared sequence for developing each output, from its definition and underlying data requirements through sources, validation, and backend implementation.

Methodology determines what the system must know. The backend implements the system required to know it.

## What is available

This first documentation release contains the methodology framework: a concise set of principles, a reusable output template, and expectations for lineage and versioning.

It is a foundation for future work. Output-specific methodologies, data models, ingestion contracts, and API documentation will be added as those decisions are made.

## How these docs will grow

Urdais documentation will expand to cover indices, markets, market analytics, maps, and news and information products. Developer documentation will describe data models, sources, ingestion, and APIs, with a changelog for published changes.

Each output will be developed one at a time. Navigation includes only documentation that is available to read.
