Discounts and separate dimensions

Models that support batch calls are billed at 50% of the real-time inference price for both input and output tokens. Context caching discounts apply to input tokens only. These two discounts cannot apply simultaneously. Batch is a separate service tier and context caching is a separate pricing dimension; neither is part of the standardized workload.

A free quota is offered only in Singapore, valid for 90 days from activation, model release, or application approval. A free quota is not a list price and is not ingested.
