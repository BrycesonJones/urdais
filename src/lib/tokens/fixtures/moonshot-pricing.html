Model Inference Pricing Explanation

Here, 1M = 1,000,000. The prices in the table represent the cost per 1M tokens consumed. Model inference APIs bill both Input and Output based on usage.

This is the international Kimi API Platform list, quoted in USD. Moonshot publishes a separate China list on its own platform in CNY, at different numbers for the same models; the two are not interchangeable and are never mixed. Prices exclude applicable taxes.
