For Claude 4.6 and later models, specifying US-only inference through the inference_geo parameter incurs a 1.1x multiplier on all token pricing categories, including input tokens, output tokens, cache writes, and cache reads. Global routing (the default) uses standard pricing. Earlier models do not support the inference_geo parameter.

Claude 4.6 and later models include the full 1M token context window at standard pricing.
